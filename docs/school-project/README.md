# Schulprojekt – OpenWarnDE 2.0

Dieses Verzeichnis enthält die Unterlagen und Projektergebnisse
des Miniprojekts LF12 im Rahmen der Vorbereitung auf die AP2.

## Projekt

**Projekt:** Neukonzeption und prototypische Entwicklung der
Warn- und Lageinformationsplattform OpenWarn 2.0

**Projektart:** Einzelprojekt

**Projektzeitraum:** 28.08.2026 – 24.01.2027

## Ausgangssystem

Die Ist-Analyse basiert auf dem bestehenden Projekt:

- [OpenWarnDEV](https://github.com/FlorianCramer/OpenWarnDEV)

## Zielprojekt

von OpenWarnDE 2.0 ein.
